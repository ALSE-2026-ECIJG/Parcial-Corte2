ClienteBancario

Proyecto final del parcial de C++. Simula cuentas de clientes bancarios (depositos, retiros, saldo y promedio de transacciones) usando programacion orientada a objetos, contenedores de la STL (std::vector), CMake y Doxygen.

Estructura

Proyecto/
├── CMakeLists.txt
├── Doxyfile
├── include/ClienteBancario.h
├── src/ClienteBancario.cpp
├── src/main.cpp
└── docs/ (documentacion HTML generada por Doxygen)

Compilacion

mkdir build && cd build
cmake ..
make
./banco

Documentacion

Abrir docs/html/index.html en el navegador. Para regenerarla:

doxygen Doxyfile
